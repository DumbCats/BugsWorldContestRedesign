      BL cheat sheet 
      PROGRAM MyBug IS
    INSTRUCTION turn-around IS
        turnleft
        turnleft
    END turn-around
BEGIN
    WHILE true DO
        IF next-is-enemy THEN
            infect
        ELSE
            move
        END IF
    END WHILE
END MyBug

      Actions (each one uses up the bug's turn): move turnleft turnright infect skip

      Conditions: next-is-empty next-is-wall next-is-friend next-is-enemy, the next-is-not-… version of each, random (heads or tails), true

      Tips: keywords are CAPITALS; names use letters, digits and -; wrap your bug in WHILE true DO … END WHILE so it never stops; make every pass through a loop do an action, or your bug loses turns.
